## 3. 当前指标的准确口径

当前相关性判定不是人工标注的 Chunk 级 qrels，而是：

```text
结果标题包含该查询任一 expected_title_keywords → 命中
```

因此：

- `Top1`：18 条查询中，首条结果标题命中的比例。
- `Top5`：18 条查询中，前 5 条至少有一个标题命中的比例。
- `MRR@5`：每条查询在前 5 条中的首个标题命中排名倒数；前 5 条无命中记为 0，再对 18 条查询取平均。

当前 `Top5` 的严格名称应为：

```text
标题关键词 Hit@5
```

它不是严格 Recall@5。严格 Recall@5 需要为每个查询标注全部相关 `chunk_id`，再计算：

```text
Recall@5 = Top5 命中的相关 Chunk 数 / 该查询全部相关 Chunk 数
```

## 4. 基线解读

1. 原始向量排序在当前旧标签下具有最高 Top1 和 MRR@5，说明 Embedding 召回并非首先失效的环节。
2. 模型重排把 Top5 从 77.8% 提高到 83.3%，但把 Top1 从 55.6% 降至 11.1%，MRR@5 从 0.639 降至 0.356。
3. 规则重排把 Top1 降至 22.2%、Top5 降至 66.7%、MRR@5 降至 0.394。
4. 上述下降不能直接证明 Rerank 模型本身有问题，因为当前住宿 Chunk 过长、不同业务类型粒度不一致，而且评测标签仍大量依赖旧标题关键词。
5. 当前 18 条测试中有 16 条把“行程”列为可接受标题关键词，但新知识库几乎已不存在对应标题，存在明显标签漂移。

### 5.2 新 qrels 口径的正式评测

新脚本应基于稳定 `chunk_id` 和 0～3 级人工相关性标注，分别报告：

- Candidate Recall@10 / Recall@20
- Rerank Recall@5
- Hit@1 / Hit@5
- MRR@5
- nDCG@5
- 分意图指标（景点、餐饮、住宿、预算、亲子、文化等）

注意：旧标题关键词指标与新 qrels 指标的相关性定义不同，不能把两者数值直接相减并宣称精度提升。真正的切片 A/B 应在同一版冻结 qrels 上同时重建两套索引后比较。
