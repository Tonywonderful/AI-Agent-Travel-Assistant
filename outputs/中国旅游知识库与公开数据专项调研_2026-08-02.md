# 中国旅游知识库与公开数据专项调研

> 核验日期：2026-08-02  
> 调研范围：中国大陆、中国香港、中国澳门、中国台湾的官方旅游数据，以及中国高校、科研机构、GitHub、Hugging Face、OpenKG 等公开渠道中的旅游知识图谱、问答数据、微调数据和旅行规划基准。  
> 本报告只研究“中国旅游数据资产本身”，不讨论任何具体软件项目的接入方案。

---

## 一、结论摘要

### 1.1 最值得优先关注的资源

| 优先级 | 资源 | 类型 | 当前可获得性 | 核心价值 | 主要限制 |
|---|---|---|---|---|---|
| A | 文化和旅游部数据服务 | 国家级权威名录 | 可匿名查询内部公开 JSON 分页接口 | 5A 景区、五星级饭店等国家级认定信息 | 字段较少；门户接口不等于已明确授予再分发权 |

| A | 中国台湾 TDX Tourism V2.1 | 统一旅游 GIS API | 注册会员并使用 API Key | 景点、餐饮、旅宿、活动、服务站、步道、自行车道，字段规范化 | 需认证；受配额、条款和再分发规则约束 |

| A- | ChinaTravel | 旅行规划 Agent 基准 | GitHub、Hugging Face、外部数据库盘 | 10 城市真实规划环境、654 条约束查询、可执行验证 DSL | 不是百科知识库；仓库和数据集未见明确许可证 |

| B+ | 西北五省旅游资源微调数据集 | 中文监督微调数据 | ScienceDB 元数据与下载流程 | 53,280 对结构化数据，覆盖五省区 | CC BY-NC-SA 4.0；来源含携程、百度百科 |
| B | 海南省旅游知识图谱 | 区域知识图谱 | 元数据公开，匿名下载受限 | 7,647 实体、14,212 关系，含景点、酒店、餐馆、交通节点 | 需登录；文件格式和完整协议待登录复核 |
| B- | Cultour | 旅游监督微调数据 | GitHub 当前仅明确保留一个桂林 JSONL | 可观察旅游知识问答的 prompt/response 结构 | 论文所述三部分未完整公开；无 LICENSE |
| C | SichuanTourismQA | 四川景点图谱工程 | GitHub 含 CSV、三元组和 Neo4j 脚本 | 可作为旅游知识图谱构建与问答工程样例 | 数据由携程爬取，MIT 只明确覆盖代码，不覆盖携程内容 |

### 1.2 核心判断

1. **中国确实存在公开的高质量旅游知识资产，但并不存在一个同时满足“全国覆盖、事实完整、持续更新、匿名下载、许可清晰、允许商用”的单一总库。**
2. 权威事实主要掌握在政府开放平台；实体关系丰富的数据主要来自科研知识图谱；复杂行程约束和 Agent 评测主要由 ChinaTravel 提供；中文问答和微调数据则多来自高校或个人仓库。
3. “网页能看”“接口能调”“仓库公开”“代码开源”是四个不同概念，均不能自动推出“旅游内容可商用、可训练、可再分发”。
4. 商业平台爬虫数据是最常见的高风险来源。携程、大众点评、去哪儿、TripAdvisor、百度百科等内容即使被放进 MIT/GPL 仓库，也不代表第三方内容权利随代码许可证一并转移。
5. 票价、开放时间、酒店价格、活动日期和客流属于高时效数据，不宜被永久固化为无时间戳的静态事实。

## 二、判定标准与访问等级

### 2.1 本报告所称“知识库”的范围

本报告将候选资源分为五类：

1. **权威事实名录**：由政府或法定机构发布的景区、酒店、街区、度假地等认定数据。
2. **结构化旅游开放数据/API**：具有字段定义、机器可读格式和更新机制的景点、住宿、餐饮、活动、统计或客流数据。
3. **知识图谱**：明确包含实体、属性、关系或三元组，可使用 RDF、CSV 三元组、Neo4j dump 等形式表达。
4. **问答/微调数据**：用于旅游问答、指令微调或知识注入的 JSON、JSONL 等语料。
5. **旅行规划基准**：包含自然语言需求、约束、交通、景点、餐馆、酒店环境及可执行评测逻辑的数据集。

### 2.2 访问等级

| 等级 | 含义 |
|---|---|
| L0 | 可匿名直接下载或调用，无需账号、Token 或审批 |
| L1 | 需要平台注册、API Key、`appKey` 或 `appsecret` |
| L2 | 需要提交申请、用途说明、负责人签字或机构审批 |
| L3 | 只有网页查询或可视化应用，未确认批量下载/API |
| L4 | 代码或页面公开，但底层数据、完整文件或许可证不清晰 |

注意：“无条件开放”有时只表示不需要数据审批，仍可能需要平台注册应用和获取 Key。

## 三、国家级与地方官方旅游数据

## 3.1 文化和旅游部数据服务

官方入口：<https://sjfw.mct.gov.cn/>

门户当前公开展示五类数据。经 2026-08-02 直接核验，其分页接口形式为：

```text
GET https://sjfw.mct.gov.cn/api/spot/list/{typeId}?page={page}
```

接口当前无需登录或 Token 即可返回 JSON，每页 20 条，分页结构如下：

```json
{
  "code": 20000,
  "data": {
    "list": [],
    "current_page": 1,
    "last_page": 18,
    "per_page": 20,
    "total": 359
  }
}
```

### 当前数据量

| typeId | 数据类别 | 当前总数 | 门户显示更新时间 | 提供部门 |
|---:|---|---:|---|---|
| 10 | 国家 5A 级旅游景区 | 359 | 2025-03-11 | 文化和旅游部政务服务门户 |
| 11 | 五星级旅游饭店 | 842 | 2026-06-25 | 文化和旅游部政务服务门户 |
| 135 | 国家级滑雪旅游度假地 | 26 | 2024-02-18 | 文化和旅游部资源开发司 |
| 138 | 国家级旅游休闲街区 | 204 | 2025-03-13 | 文化和旅游部资源开发司 |
| 143 | 国家工业旅游示范基地 | 142 | 2023-10-12 | 文化和旅游部资源开发司 |

早期网页核验曾得到 358 个 5A 景区，本次实时接口返回 359，应以带核验日期的实时结果为准。

### 典型字段

```json
{
  "id": 40685,
  "grade": 5,
  "batch": 0,
  "code": 5250030,
  "name": "安顺黄果树福朋喜来登酒店",
  "province": 520000,
  "place": "贵州省安顺市镇宁县黄果树镇博园路230号",
  "year": "2026",
  "created_at": "2026-06-25 12:20:35",
  "provinceName": "贵州"
}
```

### 评价

- **权威性：高**。适合确认国家级认定、名称、省份和评定年份。
- **知识丰富度：中低**。多数数据不含经纬度、开放时间、票价、电话、关系和历史沿革。
- **访问等级：L0（技术访问）/ L4（再分发许可）**。接口公开可访问，但门户没有因此自动授予任意复制、再分发或商业使用权。

## 3.2 地方政府开放数据代表样本

地方政务数据通常比国家名录字段更丰富，但开放条件差异很大。

| 地区与资源 | 数量 | 典型字段 | 格式/接口 | 访问判断 |
|---|---:|---|---|---|
| 宜昌市景区基本信息 | 143 | 地址、介绍、经纬度、名称、等级、状态、视频、VR | API、XLS、CSV、XML、JSON、RDF | 申请公开/受限开放，L2 |
| 烟台市 A 级景区门票客流 | 289 | 景区名称、等级、地址、门票收入、营业收入、接待人数、年份 | 库表、API、多种下载格式 | 标为无条件开放，具体调用仍需平台规则复核 |
| 丽水市庆元县景区信息 | 57 | 名称、地址、经纬度、介绍、等级、营业时段、交通、停车、联系方式 | 政务开放数据 | 年度更新；平台访问条件需逐项确认 |
| 温州市瓯海区景区基本信息 | 分页返回 | `name_xx`、`address`、`lng_gd`、`lat_gd`、`area`、`opentime`、`labels`、`introduction` | JSON API | 需要 `appsecret`，L1 |
| 资阳市景区开放信息 | 14 | 名称、地址、等级、面积、开放时间、门票价格、简介 | JSON API | 标为无条件开放，但需注册应用和 `appKey`，L1 |

### 地方开放数据的共性

- 数据字段常比国家级名录丰富，尤其是经纬度、交通、停车、开放时间和联系方式。
- 同一省市不同平台的登录、审批、Key 和下载政策可能完全不同。
- “支持 RDF”通常只是平台可导出格式，不必然意味着原数据具有完整本体和实体关系。
- 营业时间、门票、电话等字段必须保留数据更新时间和来源。

## 四、中国香港、中国澳门、中国台湾官方数据

## 4.1 中国香港：DATA.GOV.HK

官方入口：<https://data.gov.hk/>

旅游分类此前核验约有 36 个数据集。对旅游实体和行业知识最有价值的资源包括：

| 资源 | 已确认格式/能力 | 主要内容 |
|---|---|---|
| 香港主要景点 | CSV | 景点描述、地址、经纬度、电话、官方网站 |
| 持牌酒店及宾馆名单 | CSV、API | 合法住宿场所名单及牌照相关信息 |
| 香港旅游发展局举办的活动 | CSV、API | 活动名称、日期、地点等活动信息 |
| 酒店房间数、入住率、平均房价 | CSV | 住宿业统计 |
| 旅客来源、停留时间与消费 | CSV、JSON、XLSX、部分 API | 旅游市场与游客行为统计 |

补充资源还分布在 Culture、Recreation、Transport 等分类中，包括法定古迹、历史路线、远足径、文化活动和公共交通。

- **访问等级：多数 L0，部分 API 以具体资源说明为准。**
- **优点：**机器可读性强，字段和更新机制相对清晰。
- **限制：**需逐项引用 DATA.GOV.HK 的使用条款；旅游相关资源并不集中在单一分类。

## 4.2 中国澳门：政府数据开放平台与旅游局

官方入口：<https://data.gov.mo/>

### 已核验的住宿数据

“酒店/经济型住宿场所/公寓式酒店资料”具有以下公开元数据：

- 提供者：中国澳门旅游局；
- 开放条件：完全开放；
- 格式：XML；
- 更新频率：每日；
- 提供文件下载和目录 API；
- API/下载线索：

```text
https://api.data.gov.mo/document/download/6dafc514-7fc6-4d4e-9468-8772ba1c3b44?
```

字段包括多语言名称、地址、经纬度、联系方式和环保酒店标识等。

### 其他可用资源

- 酒店入住率、平均房价等旅游统计；
- “澳门旅游数据+”中的月度和区域旅游统计，可下载 Excel；
- 24 个统计区的游客量、平均停留时间和每小时平均访客量；
- 旅游局已公开发布多项旅游相关数据集，历史公开说明提及约 25 项；
- “智慧客流应用”当前可查看约 114 个景点的人流状况。

### 边界

- 智慧客流目前可以确认为网页应用，但未确认存在无需认证的批量 API，故应标为 **L3**。
- 政府开放数据平台使用动态渲染，自动抓取首页可能错误显示“0 个数据集”，不能据此认定资源不存在。
- 住宿 XML 数据可视为 **L0**，但仍应遵循平台条款和署名要求。

## 4.3 中国台湾：TDX Tourism V2.1

官方入口：<https://tdx.transportdata.tw/>

TDX 与观光主管部门提供统一的观光 GIS API。V2.1 已确认覆盖：

- 景点；
- 餐饮；
- 旅宿；
- 活动；
- 旅游服务站点；
- 步道；
- 自行车道。

主要 OData 端点包括：

```text
/service/odata/V2/Tourism/Attraction
/service/odata/V2/Tourism/Restaurant
/service/odata/V2/Tourism/Hotel
/service/odata/V2/Tourism/Event
```

可以使用 OData 条件按行政区过滤，例如：

```text
PostalAddress/City eq '宜蘭縣'
```

V2.1 标准包含 UID、多语言代码、行政区代码、坐标、营运状态、景点类型、文化资产等级、料理类型、旅宿类型、星级和认证等规范化字段。

- **认证：**需注册 TDX 会员并使用 API Key，访问等级 L1。
- **版本：**旧版 V1.0 的官方下架日期为 **2026-12-31**。
- **许可边界：**第三方观光服务当前可免费使用，但“免费”不等于没有配额、署名、使用条款或再分发限制。

## 五、真正的旅游知识图谱

- DOI：<https://doi.org/10.57760/sciencedb.j00001.01065>
- CSTR：`31253.11.sciencedb.j00001.01065`

- 首次发布：2024-10-17；

- 版本：V2。

### 规模和文件

| 指标 | 数值 |
|---|---:|
| 实体数 | 30,045 |
| 关系类型 | 14 |
| 三元组数 | 810,793 |
| 数据量 | 60.26 MB |
| 文件数 | 3 个 CSV |

```text
甘肃nodes.csv
甘肃relations.csv
甘肃triples.csv
```

- **评价：**这是目前检索到的中国境内区域旅游知识图谱中规模大、文件结构清晰、实体关系丰富且下载状态较明确的一项。
- **风险：**即使数据集以 CC BY-NC 发布，底层商业平台内容的权利边界仍值得单独复核。

## 5.2 OpenKG 中国旅游景点知识图谱

资源页：<http://data.openkg.cn/dataset/tourist-attraction/resource/dbed4401-a870-4118-95a5-edaccc968ae6>

- 创建机构：中国科学院自动化研究所；
- 属于 CASIA-KB 的一部分；
- 内容：中文旅游景点知识；
- 来源：百度百科和互动百科；
- 格式：RDF；
- 授权字段：Creative Commons Attribution；
- 创建和最后更新时间：2017-01-17；
- 资源状态：active，但无在线预览，`Datastore active=False`；
- 历史检索页显示下载量约 8,950 次。

### 评价

- **优点：**是少数明确以 RDF 发布、并带 CC Attribution 授权字段的中国旅游景点知识图谱。
- **不足：**页面未公开展示实体数、三元组数和当前数据样例；数据年份较早；来源百科内容可能存在时效和历史权利边界。
- **访问等级：**资源页显示为上传型资源，技术下载状态需实际点击复核；当前可保守标记为 L0/L4 之间。

## 5.3 海南省旅游知识图谱

- CSTR：`16666.11.nbsdc.hzttREUI`
- 创建机构：海南大学；
- 采集时间：2019-07 至 2022-06；
- 实体数：7,647；
- 关系数：14,212；

实体包括区镇乡、地县级市、景点、机场、火车站、省份、酒店和餐馆；主要关系为 `belongs_to` 和 `located_at`。数据主要来自互联网爬虫。

- 页面历史信息曾标为“完全共享”；
- 当前匿名访问返回“暂无权限，请先注册或登录”；
- 因此只能确认元数据，文件名、格式和完整许可需登录后复核；
- **访问等级：L1/L4。**

## 六、中文旅游问答与监督微调数据

## 6.1 西北五省旅游资源微调数据集

- DOI：<https://doi.org/10.57760/sciencedb.j00001.01088>
- 覆盖：甘肃、宁夏、青海、陕西、新疆；

## 九、许可证与合规矩阵

| 情况 | 能否直接认定可商用 | 原因 |
|---|---|---|
| 官方网页公开展示 | 否 | 公开可见不等于授予复制、批量抓取或再分发权 |
| 官方接口无需 Token | 否 | 技术可访问与法律许可是两回事 |
| 标注“无条件开放” | 不一定 | 可能仍需账号、Key、署名并遵循平台协议 |
| CC BY | 通常可以，但需逐条核验 | 需署名，且发布者必须有权许可底层内容 |
| CC BY-NC | 否 | 明确禁止商业使用 |
| CC BY-NC-SA | 否 | 禁止商业使用，衍生物还需相同方式共享 |
| GitHub MIT/Apache/GPL | 只明确覆盖有权许可的仓库内容 | 不自动覆盖携程、大众点评、百度百科等第三方文本 |
| GitHub/Hugging Face 无 LICENSE | 否 | 默认不能推定复制、修改、训练和商用权利 |
| 科研平台“完全共享” | 不一定 | 可能仍要求登录、用途申请或机构审批 |
| 商业平台爬虫数据 | 高风险 | 可能涉及服务条款、数据库权益、著作权、反爬限制和个人信息 |

### 9.1 动态事实的特别要求

以下字段必须带来源与更新时间，且应定期重新核验：

- 门票价格及优惠政策；
- 景区开放时间和临时关闭状态；
- 酒店价格、房量和营业状态；
- 活动日期、场次和地点；
- 航班、列车和公共交通时刻；
- 实时或预测客流；
- 餐厅营业时间、人均价格和评分。

### 9.2 研究和商业使用建议

- **非商业科研优先：**甘肃旅游知识图谱、西北五省微调数据、AttractionDetailsQA、ChinaTravel（仍需确认其许可）。
- **权威事实核验优先：**文化和旅游部、各地政府开放平台、中国香港 DATA.GOV.HK、中国澳门政府开放数据、中国台湾 TDX。
- **商业使用前必须补充书面核验：**所有无 LICENSE 仓库、所有含商业平台抓取内容的数据集、所有仅标“完全共享”或“无条件开放”但未展示完整协议的数据。
- **不建议直接复用：**没有许可证的个人仓库、来源不清的聚合 CSV、已删除主要数据文件的仓库、只有爬虫代码而没有内容授权的数据。

### 第一层：权威事实源

### 第二层：实体关系和知识图谱

1. 甘肃旅游知识注入数据集 V2；
2. OpenKG 中国旅游景点知识图谱；
3. 海南省旅游知识图谱（需登录复核）；

## 十二、一句话结论

如果目标是寻找“中国旅游知识库”，最合理的理解不是寻找一个万能下载包，而是将资源分成四条独立证据链：**政府权威事实、科研知识图谱、中文问答/微调语料、旅行规划评测环境**。目前综合质量最高的代表分别是文化和旅游部及地区官方开放数据、甘肃旅游知识图谱、AttractionDetailsQA/西北五省微调数据，以及 ChinaTravel；任何商业使用都必须继续核验数据条款，而不能仅凭“公开可访问”或“GitHub 有许可证”下结论。
